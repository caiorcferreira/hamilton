# Hamilton 0.9.0

## Breaking changes

- The Effect-generated global CLI flags `--completions`, `--log-level`, and `--wizard` are removed. Invoking any of them is rejected as a usage error with exit code `2`.
- A `hamilton setup` failure now exits with status `2` instead of `0`; successful setup continues to exit `0`.

## Installation

Install the platform-specific standalone Bun executable and its sidecar `bundle/` with the install script. The executable runs without Bun, Node, or a Hamilton source checkout.

```bash
curl -fsSL https://raw.githubusercontent.com/caiorcferreira/hamilton/main/install.sh | bash
npx skills add https://github.com/caiorcferreira/hamilton
```

The install script downloads the standalone executable and bundle archive for the release, verifies both against the release checksums, installs the executable on `PATH`, unpacks the bundle beside it, and runs assisted setup. The second command installs the skills in your coding agent.
