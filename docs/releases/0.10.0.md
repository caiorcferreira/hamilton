# Kepler 0.10.0

This is the first release built from Kepler's two-package workspace and release asset format.

## Breaking changes

- The CLI executable and command are now `kepler`. The old `hamilton` command is not provided as an alias.
- Global data now lives at `${XDG_CONFIG_HOME:-$HOME/.config}/.vialactea-works/kepler/`. `kepler setup` copies legacy `~/.hamilton/` data only when the new path does not exist, and leaves the source unchanged.
- Workbench project artifacts now live under `.kepler/`. Kepler copies legacy `.hamilton/` project data only when `.kepler/` does not exist. If both paths exist, Kepler uses `.kepler/` without merging or changing the legacy path.

## Packages and release assets

The workspace contains `@vialactea-works/kepler-cli` and `@vialactea-works/kepler-core`. Each GitHub release includes standalone platform binaries, `kepler-bundle.tar.gz`, the versioned `kepler-core-0.10.0.tgz` tarball, and `SHA256SUMS`. The core tarball is attached to this release asset set; publishing it to GitHub Packages is a separate workflow step.

## Installation

Install the standalone executable and sidecar bundle with the release installer:

```bash
curl -fsSL https://raw.githubusercontent.com/vialactea-works/kepler/main/install.sh | bash
npx skills add https://github.com/vialactea-works/kepler
```

The installer verifies the binary and bundle checksums, installs `kepler` on `PATH`, extracts the bundle beside it, and runs assisted setup. The second command installs the Kepler skills in your coding agent.
