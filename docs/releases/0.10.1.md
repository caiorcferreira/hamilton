# Kepler 0.10.1

## Fixes

- Use `kepler workbench lint` as the sole authority for existing artifact format and schema validity. Pipeline skills and templates no longer reject lint-valid artifacts for accepted extra content or layout differences.
- Accept `MODIFIED`, `REMOVED`, and `RENAMED` requirements deltas without requiring an `ADDED` section.
- Accept the critique-specific `applied` decision value while retaining the shared decision vocabulary for other artifacts.

## Packages and release assets

The workspace contains `@vialactea-works/kepler-cli` and `@vialactea-works/kepler-core`. GitHub releases include standalone platform binaries, `kepler-bundle.tar.gz`, the versioned `kepler-core-0.10.1.tgz` tarball, and `SHA256SUMS`. The release workflow also publishes the core package to GitHub Packages.

## Installation

Install the standalone executable and sidecar bundle with the release installer:

```bash
curl -fsSL https://raw.githubusercontent.com/vialactea-works/kepler/main/install.sh | bash
npx skills add https://github.com/vialactea-works/kepler
```

The installer verifies the binary and bundle checksums, installs `kepler` on `PATH`, extracts the bundle beside it, and runs assisted setup. The second command installs the Kepler skills in your coding agent.
